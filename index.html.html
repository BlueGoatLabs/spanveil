Getting your export

  • Open the Usage or Cost page in your OpenAI or Anthropic dashboard.
  • Look for an Export or Download CSV button and pick the last 30 days.
  • Drop the file here. If a column is guessed wrong, fix it in the mapper.

Costs are read as USD. Rows with a bad date or negative amount are skipped.

Advanced: connect an Admin API key for live data
Heads up: Admin keys have organization-level permissions. If you're not sure, use the CSV route above. If you connect, use a dedicated key you can revoke at any time.

🟢 OpenAI Not connected

Create one at platform.openai.com → Settings → Organization → Admin keys. Project keys (sk-…) can't read org usage.

🟣 Anthropic Not connected

Create one at console.anthropic.com → Settings → Admin keys. Regular API keys can't read org usage.

🔒 How keys are handled: a key is held in memory only, sent over HTTPS to Spanveil's API for one request against the provider, then cleared from this page. It is never stored, logged, or written to a database.
